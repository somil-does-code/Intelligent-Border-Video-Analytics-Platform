# IBVAP — Intelligent Border Video Analytics Platform

Hackathon prototype: an AI-inspired border surveillance command dashboard connected to a Flask backend.

## Deploy on Render

This repository is prepared for Render deployment.

- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 120`
- Demo mode works without a camera or AI model.
- The web deployment intentionally uses lightweight dependencies so the dashboard can deploy reliably on a basic web host.

## Run locally

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Prototype controls

- Switch between Sector A-3, B-1 and C-4.
- Generate demonstration alerts.
- Demo CCTV frames are generated by the Flask backend.
- AI mode is retained for local environments where the original YOLO/ANPR dependencies and model files are installed.

> This is a hackathon prototype and is not validated for real-world border-security operations.
